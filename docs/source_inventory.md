## Scope and limitations

The report describes field collection through local fishermen, specimen handling, anatomical sampling, enrichment, culture, Gram staining, microscopy, catalase, urease, indole and Kligler iron agar tests. It does not contain linked specimen-by-site results, sampling coordinates, isolate confirmation by molecular or serological methods, or clear records of which individual performed each bench procedure. The proposal names additional *planned* procedures (XLD, coagulase, citrate, TSI/IMViC); these should not be represented as completed methods without separate evidence. The final report describes some controls and triplicate plating, but raw control records and plate counts were not supplied.

The report results pp15–16 and abstract agree on the 12 counts. The report discussion pp20–21 contains internal inconsistencies; see [source reconciliation](source_reconciliation.md). The abstract's inferential test and linked specimen data are not available. Further work could use authenticated specimen-level records, isolate confirmation, sampling metadata and a documented paired statistical analysis.
