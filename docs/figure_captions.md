# Figure captions

All new figures are generated by `python -m src.visualization` from the 12 `published_abstract` rows in `data/processed/organ_detection_summary.csv`, transcribed from supplied abstract PP–137, printed p189. The report results pp15–16 independently match these counts. PNG and SVG versions are in `figures/`.

1. **Heatmap:** cell = 100 × positive count / 27, rounded to one decimal. Rows are reported organism groups; columns are anatomical sites.
2. **Grouped bars:** same proportions with exact published count labels. Bar height is detection frequency, not bacterial load.
3. **Wilson intervals:** point = positive count / 27; whiskers = two-sided 95% Wilson score limits for each marginal proportion. No interval is for a paired site difference.
4. **Organ profiles:** independent site categories in small multiples; no continuous anatomical axis is implied.
5. **Workflow:** reconstruction of steps documented in the report p13 and abstract p189. Statistical analysis is the later computational extension.
6. **Source comparison:** report results p15, report discussion pp20–21, and published abstract p189. The 22/25 percentage is recalculated, and the Shigella discrepancy is flagged rather than silently corrected.

Original embedded laboratory figures have a separate [image inventory](../assets/wet_lab/image_inventory.csv), including original report page, figure number and rights status.
